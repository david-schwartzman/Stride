# Badge

Small label that flags a product or line state.

| tone | use |
| --- | --- |
| `guide` | volt tint — beginner guidance — *Good for your first 5K*, *Great for trails*. Sentence case, one per card |
| `new` | volt — *Just in*, *New*, max one per card |
| `inverse` | *Best seller* |
| `neutral` | *Out of stock*, *Only 2 left* |
| `success` | *In stock*, *Order placed* |
| `inverse` | *Race day* picks |
| `sale` | error-volt tone; v1 has no discounts, so use only for problems (e.g. *Payment failed*) |

Never more than one status badge on a product card (the guide tag is separate). Keep status badges to 1–3 words.
